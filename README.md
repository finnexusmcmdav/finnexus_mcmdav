# Finnexus — The Commerce Society

Official website for Finnexus, the commerce club of MCM DAV College for Women, Chandigarh.

## Structure

```
index.html          Main site (single page)
assets/
  finnexus-logo.png  Site logo / favicon (add this file)
  finnexus-hero.png  Hero coin illustration (add this file)
  team/              Team member photos
```

## Running locally

This is a static site — no build step. Just open `index.html` in a browser, or serve the folder with any static server, e.g.:

```
npx serve .
```

## Deploying

Hosted via GitHub Pages from this repo. See repo settings → Pages.
